# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/morthasandeep777/sandeep-mortha-portfolio.git
```

Go into the project

```bash
cd sandeep-mortha-portfolio
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```
